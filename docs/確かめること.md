# 人が確かめること

このアプリに入れた典拠のうち、**わたしたちでは決められなかったもの**の一覧です。
書いた本人（AI）が「ここは自分の知識では確かめきれない」と申告したところだけを、
聖典ごとに並べてあります。

- **本を開く順に並べてあります。** 上から順でなく、手元にある本のところから。
- **済んだら、その行の頭を `- [x]` にしてください。**
- 直しは開発の側でします。ここには結果だけ書いていただければ十分です。
- 右の `（ )` は、どの材料の話かの目印です。

## 『教行信証』

### 行巻・他力を釈する段
- [ ] 「他力といふは如来の本願力なり」が、**聖人の地の文か、曇鸞『往生論註』の引用か**
      （`tariki-1` `tarikihongan-1`／一節の棚にも入っています）
      → 引用なら、一節の出どころに曇鸞の名を足せます。棚をまたいで引けるようになります。

### 行巻・正信念仏偈
- [ ] **龍樹章 十二句**（「釈迦如来楞伽山…」から「唯能常称如来号　応報大悲弘誓恩」まで）
      とくに「顕示難行陸路苦　信楽易行水道楽」と、**その次の「憶念弥陀仏本願　自然即時入必定」**
      → 訓点が「難行の陸路**、**苦しきこと」か「陸路**の**苦しきこと」か。
        「自然に即の時必定に入る」か「即の時**に**」か（`shoshinge-ryuuju`）
- [ ] **道綽章「道綽決聖道難証　唯明浄土可通入」**
      → 「証しがたき**こと**を決して」か。「決して」が決判の意であることを返点・左訓で（`shoshinge-doushaku`）
- [ ] **道綽章の次聯「万善自力貶勤修」**
      → 注意書きの言い方が、この聯と食い違っていないか
- [ ] **源空章「本師源空明仏教　憐愍善悪凡夫人」**
      → **語尾が「憐愍せしむ」か「憐愍したまう（したまえり）」か。いま「せしむ」で置いてありますが未確定です**（`shoshinge-genku`）
- [ ] **天親章「天親菩薩造論説　帰命無碍光如来」**（`tenjin`）
- [ ] **曇鸞章「三蔵流支授浄教　焚焼仙経帰楽邦」**（`donran`）
- [ ] **字体** — 顕/顯、証/證、楽/樂、仏/佛。いまアプリは全部新字体で揃えています。

### 信巻

### 証巻・教巻
- [ ] **教巻冒頭** — 「二種の回向あり。一つには往相、二つには還相なり」（**二種回向を立てるのは教巻**）
- [ ] **証巻の還相を釈するくだり** — 曇鸞『浄土論註』の出第五門を引き、「生死の稠林に回入して、一切衆生を教化し」

      （この一点で、通夜用の案を一件取り下げました）
- [ ] 「亡くなった身近な人が還ってはたらく」と読める文言があるか（`gensou-1` `gensou-2` `ojodo-1` `ojodo-2`）
- [ ] **証巻、還相回向を釈する段**（「二に還相の回向といふは、すなはち利他教化地の益なり」の前後）— `gensou-5` の `core`「お浄土に生まれた方は、こちらへ還って、私どもが教えを聞く縁をひらいてくださる」が、この段の言い換えとして許せるか。上の「一切衆生を教化し」との距離、とくに**「私ども」に絞ってよいか**。許せなければ `core` を外す。`source` を段まで絞れたら絞る。
