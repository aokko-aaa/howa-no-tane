# 聞いた感想

予定（Routine）が書いた話の案を、**読んで（できれば声に出して）どう感じたか**を
書いていただく場所です。次の回は、ここを最初に読んでから書きます。

- **一言で十分です。** 「使える」「この席では無理」「ここの一語が重すぎる」など。
- どの項目にも答えなくてかまいません。気になったところだけ。
- 書き終えたら、見出しの `（感想待ち）` を `（感想あり）` に変えてください。
  次の回はそれを目印にして読みます。
- 書き方の傾向として受け取ったことは、`docs/書き方の覚え.md` に移します。
  ここの感想そのものは消しません。

聞きたいこと（目安）

1. 席で、このまま口にできそうか。できないなら、どの一語か
2. 聴いている人の顔が浮かんだか。浮かんだのは、どんな人か
3. 重すぎる・軽すぎる・説教くさい、と感じたところ
4. 入口の場面は、いまの門徒さんの暮らしにあるか
5. 次はこういう案がほしい、ということ
